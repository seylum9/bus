# 安謝橋〜那覇バスターミナル・旭橋（B） 時刻表

## 目的と対象範囲

ユーザーの定期券で利用できる、安謝橋〜那覇バスターミナル・旭橋（B）間の時刻表を作る。
路線全体の案内ではなく、この区間で日常的にバスを利用するためのアプリとする。

- 区間：安謝橋〜那覇バスターミナル・旭橋（B）。途中の停留所も含む。旭橋（B）まで定期で利用できることをユーザー確認済み。
- 方向：安謝橋から那覇バスターミナル・旭橋（B）方面、および那覇バスターミナルから安謝橋方面。旭橋（B）は那覇方面の停留所として扱う。
- 運行日：平日・土曜日・日曜日・祝日を扱い、元の時刻表の運行日区分に従う。
- 区間外の停留所・時刻は表示対象にしない。

## 定期券で利用できる路線

2026年9月15日にユーザーが指定した、次の18路線を対象とする。

**20・23・24・26・27・28・29・32・43・52・63・80・92・110・120・132・143・385**

- 31番など、この一覧にない路線は対象外。
- 対象路線の一覧はユーザー確認済み。各路線・便の停車区間や経由は元の時刻表で確認する。
- 経由による定期券の利用制限の有無は未確認。路線一覧だけから推定しない。

## 現在のファイル構成

- `index.html`：画面と表示処理。
- `timetable-data.js`：照合用の従来データと、画面で使う方向・停留所の設定。従来の時刻は表示に使わない。
- `timetable-20-120.js`：保存済みHTMLから生成した20・120番の表示用データ。
- `timetable-23.js`：保存済みHTMLから生成した23番の表示用データ。
- `timetable-24-27-80-92-110.js`：保存済みHTMLから生成した24・27・80・92・110番の表示用データ。
- `timetable-26.js`：保存済みHTMLから生成した26番の表示用データ。
- `timetable-28-29.js`：保存済みHTMLから生成した28・29番の表示用データ。
- `timetable-63.js`：保存済みHTMLから生成した63番の表示用データ。
- `timetable-32-43-132-143-385.js`：保存済みHTMLから生成した32・43・132・143・385番の表示用データ。
- `timetable-52.js`：保存済みHTMLから生成した52番の表示用データ。
- `timetable.js`：全18路線の生成データを返す表示用の処理。那覇方面の停留所選択には旭橋（B）も含む。

現状の時刻表は保存済みデータを表示する。自動更新や遅延情報の取り込みは行っていない。
接近情報は「のりものNAVI Okinawa（旧バスなび沖縄）」への外部リンクで確認する。
画面はタブ切り替えなしで時刻表を表示する。便をタップした詳細の「この路線の現在位置を見る」から、選択中の停留所を基準に、路線・方向に合うページを別タブで開く。
停留所IDは2026年9月15日に[公式の停留所検索](https://www.busnavi-okinawa.com/mobile/Timetable/DepartureSearch)で確認した。天久などの両方向・美栄橋経由の各停留所・旭橋（B）に対応する。旭橋（B）の公式ページ上の名称は「旭橋・那覇バスターミナル（公園前向け）」。
泊高橋は便の経由で乗り場を分け、那覇BTは路線ごとの乗り場を表示する。那覇BT発の27・32番は乗り場が複数あるため、それぞれのリンクを表示し、便との対応を推測しない。
リンク先は同じ路線・方向の現在位置で、選択した便・経由・時刻には絞り込まれない。停留所の対応が不明な場合は安謝橋のリンクで代用しない。
下りの路線IDと停留所IDは、2026年9月15日に[安謝橋（第二城間・パイプライン向け）の公式ページ](https://www.busnavi-okinawa.com/mobile/Timetable/TimeAndApproach?stationSid=331d72e2-8a28-482a-8c2e-976c570e15da&fromType=stationSearch)で確認した。
対象18路線は保存済み原本との抽出・照合が完了。事業者の最新ダイヤとの照合や、取得日以降の変更確認は別途必要。

## 20・120番の変換と照合

Node.js 22以上で、プロジェクトのフォルダから実行する。追加パッケージやネットワーク接続は不要。

```sh
node scripts/import-20-120.mjs
node --test scripts/import-20-120.test.mjs
node --test scripts/timetable.test.mjs
```

入力は `data/source/20_120/2026-11-07/` の6ページと `source.json`。2026年10月19日実施のダイヤ。
別の取得日のフォルダを使う場合は `node scripts/import-20-120.mjs data/source/20_120/YYYY-MM-DD` と指定する。
出力は `data/processed/20_120/取得日/` に生成し、再実行するとそのフォルダの生成ファイルを更新する。

- `timetable.json`：便ごとの系統・経由・対象区間の停車時刻・元ページ情報。
- `comparison.json`：`timetable-data.js` との機械可読の差分。比較元のハッシュも記録。
- `comparison.md`：便数・停留所時刻数と差分の一覧。

併せてプロジェクト直下の `timetable-20-120.js` を生成する。画面の20・120番はこのデータを使用し、既存データとの重複表示を避ける。

取り込み時は原本のハッシュ、曜日表示、列数、時刻、停留所、経由、重複を検証し、不明な構造はエラーにする。
日曜日は `down3/up3`、祝日は `down2/up2` を使う。元ページの注記に従い、年末年始（12月31日〜1月3日）と旧暦7月15日のお盆は日曜ダイヤとして記録する。
画面の曜日選択は「平日」「土曜」「日曜」「祝日」。20・120番の祝日は土曜ダイヤ、23番は注記を適用した祝日ダイヤ、それ以外は各路線の原本の日祝・土休日区分を使う。
祝日・旧暦の日付判定は自動化していないため、祝日は手動で「祝日」、20・120番の上記の例外日は「日曜」を選ぶ。

那覇方面行きの120番は元表の那覇BT欄が通過記号なので、時刻を補わない。
その先の原本の「旭橋」は「旭橋（B）」として抽出する。那覇BTとは別の停留所として表示・照合し、時刻を代用しない。
既存の `timetable-data.js` は照合用と方向・停留所の設定用に保持し、スクリプトでは書き換えない。
公開時は `index.html` と10個のJavaScriptファイル（`timetable-data.js`・`timetable-20-120.js`・`timetable-23.js`・`timetable-24-27-80-92-110.js`・`timetable-26.js`・`timetable-28-29.js`・`timetable-63.js`・`timetable-32-43-132-143-385.js`・`timetable-52.js`・`timetable.js`）を同じフォルダに置く。

## 23番の変換と照合

```sh
node scripts/import-23.mjs
node --test scripts/*.test.mjs
```

入力は `data/source/23_31_223_331/2026-09-15/`。23番のみを抽出し、31・223・331番を除外する。
別の取得日のフォルダを使う場合はコマンドの引数に指定する。
出力は `data/processed/23/取得日/` の `timetable.json`・`comparison.json`・`comparison.md` と、画面用の `timetable-23.js`。
原本の6ページを保持し、表示用には平日・土曜・日曜・祝日の両方向8区分を作る。

- `a`：日曜日運休（祝日運行）。土曜は運行する。
- `b`：日曜日運行（祝日運休）。土曜の表にも載っているが、日曜日運行の注記に従って土曜からは除外する。
- `D`：基幹急行でいごライナー。区間内で実際に停車する停留所だけに表示し、「急行」と明記する。安謝橋などの通過欄に時刻を補わない。
- 12月31日〜1月3日と旧暦7月15日のお盆は、画面で「日曜」を選択する。

23番の平日は既存の時刻・経由と一致。土曜・日曜・祝日はa/b注記を反映し、各方向で運休対象の1便を除外している。
